# 🐟 Fish Fighters  

**Fish Fighters** is a **horizontal tower defense game** where you deploy units of fish to battle waves of enemies. The game is heavily inspired by *The Battle Cats*, but with an aquatic twist.  

⚠️ **Note:** This project is still **work in progress**. Many mechanics, visuals, and assets are placeholders and subject to change.  

---

## 🎮 Gameplay Overview  

- Deploy different **fish units** to defend your base.  
- Units automatically **walk, attack, and knock back enemies**.  
- Gameplay takes place on a **2D side-scrolling battlefield**.  
- Strategy is key — manage your deployment timing and unit composition.  

---

## ✨ Current Features  

- Core **state machine** for unit behavior:  
  - Idle  
  - Walking  
  - Attacking  
  - Knockback  
  - Dead  
- Basic **stage system** (units and enemies spawn and fight).  
- Early **combat interactions** (health, cooldowns, attack ranges).  

---

## 🛠️ Tech Stack  

- **C++** for game logic  
- Custom **state machine architecture** for unit AI  
- Uses **tweeny** for smooth knockback animations
